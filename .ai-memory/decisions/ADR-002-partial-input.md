# ADR-002: سیستم ورود جزئی (Partial Input)

> **تاریخ:** 1405/05/27
> **وضعیت:** ✅ تصویب شده

---

## زمینه

کاربر نمی‌تواند همیشه همه کارها را کامل انجام دهد.
مثلاً ۵ دقیقه از ۳۰ دقیقه پیاده‌روی، یا نماز قبل از طلوع (نه اول وقت).

## تصمیم

چهار نوع تسک طراحی شد:

| Type  | Example   | Data                        |
| ----- | --------- | --------------------------- |
| `qty` | walk      | `{v: 5000}` (steps)         |
| `win` | fajr_pray | `{v: 'prime'}` (window)     |
| `chk` | reset_r   | `{v: [1,1,0,1]}` (subtasks) |
| `lv`  | legacy    | `{v: 2}` (level)            |

## فرمول امتیاز

ratio = done / target
ratio >= 1.0 → عالی (100%)
ratio >= 0.5 → معمول (70%)
done >= sv → بقا (30%) ← زنجیره حفظ می‌شود!
done > 0 → جرقه (15%)
done = 0 → نشد (0%)

## دلایل

1. **انعطاف** - کاربر می‌تواند هر چقدر که توانست انجام دهد
2. **انگیزه** - هر قدم کوچک پاداش دارد
3. **واقع‌بینی** - زندگی واقعی غیرقابل پیش‌بینی است

## مثال

```php
// data.php
[
    'id' => 'walk',
    'ty' => 'qty',
    'tg' => 7000,   // target
    'sv' => 1000,   // survival value
    'u' => 'قدم'
]

```
