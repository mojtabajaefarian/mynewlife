# ADR-001: سیستم احراز هویت ساده

> **تاریخ:** 1405/05/27
> **وضعیت:** ✅ تصویب شده
> **تصمیم‌گیرنده:** مجتبی + AI

---

## زمینه

پروژه نیاز به محافظت از داده‌های کاربر دارد. گزینه‌ها:

1. OAuth (Google, GitHub)
2. سیستم لاگین ساده با رمز
3. بدون لاگین (public)

## تصمیم

**سیستم لاگین ساده با رمز** انتخاب شد.

## دلایل

| دلیل                    | وزن  |
| ----------------------- | ---- |
| سادگی پیاده‌سازی        | بالا |
| تک‌کاربره بودن پروژه    | بالا |
| عدم نیاز به ایمیل       | بالا |
| سازگاری با هاست اشتراکی | بالا |

## راه‌حل پیاده‌سازی

```php
// auth.php
function verify_password($input, $hash) {
    return password_verify($input, $hash);
}

function login_attempt($password) {
    $settings = load_settings();
    if (verify_password($password, $settings['password_hash'])) {
        $_SESSION['authenticated'] = true;
        return true;
    }
    return false;
}
```
