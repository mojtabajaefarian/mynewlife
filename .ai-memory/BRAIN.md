## 🔑 اصول کلیدی پروژه

### ۱. فلسفه طراحی

- **کوچک اما هر روز > بزرگ اما هرگز**
- **تداوم مهم‌تر از کمال است**
- **استمرار در کارهای کوچک، قوی‌تر از انفجارهای انگیزه‌ای**
- **زنجیره نباید بشکند - حتی اگر امروز فقط بقا بود**

### ۲. قوانین طلایی (غیرقابل مذاکره)

| #   | قانون                      | توضیح                                     |
| --- | -------------------------- | ----------------------------------------- |
| ۱   | **هرگز دو روز پشت هم صفر** | یک روز خطا عادی است، دو روز سقوط          |
| ۲   | **قانون نصف کردن**         | توان نداری؟ نصفش کن. باز هم نه؟ یک تکرار  |
| ۳   | **ممنوعیت جبران**          | روز از دست رفته جبران نمی‌شود             |
| ۴   | **حذف مجاز است**           | در روز سخت، بلوک‌های غیرستاره حذف می‌شوند |
| ۵   | **لنگر محور نه ساعت محور** | ساعت‌ها تقریبی، لنگرها قطعی               |
| ۶   | **بقا هم امتیاز دارد**     | حتی حالت بقا، زنجیره را نگه می‌دارد       |

### ۳. الگوی ورود جزئی (Partial Input)

**مشکل حل‌شده:** کاربر نمی‌توانست بگوید "۵ دقیقه از ۳۰ دقیقه پیاده‌روی" یا "نماز صبح قبل از طلوع خواندم".

**راه‌حل:** چهار نوع تسک:

- `qty` → کمّی (عدد + هدف + حداقل بقا)
- `win` → پنجره‌ای (prime/valid/qada/miss) - مخصوص نماز
- `chk` → چک‌لیستی (زیرموارد)
- `lv` → سه‌سطحی دستی (legacy)

**فرمول امتیاز:**
ratio = done / target
ratio ≥ 1.0 → عالی (lv=3, 100%)
ratio ≥ 0.5 → معمول (lv=2, 70%)
done ≥ sv → بقا (lv=1, 30%) ← زنجیره نمی‌شکند!
done > 0 → جرقه (lv=1, 15%)
done = 0 → نشد (lv=0, 0%)
